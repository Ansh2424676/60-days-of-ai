# Day 45 – AI Decision Strategist

## Overview

Built an AI-powered Decision Intelligence dashboard using Claude AI.

The application guides users through structured decision-making using a four-question interview and generates an interactive Decision Report.

---

## Features

- Structured interview
- Decision Matrix
- Assumption Buster
- Premortem Analysis
- 7-Day Test Plan
- Interactive HTML Dashboard
- Animated Progress Bars
- Shareable Summary Cards
- Responsive Design
